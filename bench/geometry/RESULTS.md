# autodyne geometry vs glam

Generated by `cargo run --release` in `bench/geometry` (glam 0.30, x86_64). Each case checks that the two agree, then times both over
the same 1024 inputs (independent operations) in 101 alternating rounds; times are each side's best round per pass.

- Relative = glam's time / autodyne's (above 1: autodyne is faster).
- Agree = the largest difference between the two results, relative to the largest value.
- Across builds, where the code lands alone moves the single-value cases by up to ~8% (glam's own Mat4 product measured
  3.14 and 3.40 µs in two builds of this harness), so within that read as parity.
