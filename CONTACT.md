# Contact

Write to vabsgop@gmail.com or vabsgop@proton.me about autodyne, with one of these subjects so it reaches the right place:

| For | Subject |
|---|---|
| A commercial license | `[autodyne] Commercial license: <your company or product>` |
| Whether the royalty-free license covers you, or its attribution | `[autodyne] Royalty-free license: <your question>` |
| A security problem (privately; see [SECURITY.md](SECURITY.md)) | `[autodyne] Security: <a short summary>` |
| Anything else | `[autodyne] <topic>` |

Bugs and feature requests go in the repository's issues.
