# Contributing to autodyne

autodyne doesn't take code contributions: only its licensor commits to it, so pull requests aren't accepted
([LICENSE.md](LICENSE.md#contributing)).

Issues are welcome: bug reports (what you ran, what you expected, what happened, ideally a small program that
shows it), feature requests (what you're building and what's missing), and questions. Security problems go
privately, as [SECURITY.md](SECURITY.md) says; anything else about autodyne, [CONTACT.md](CONTACT.md).
